# FitTrack — Ρόλοι, use cases και κανόνες

**Έκδοση:** 0.1  
**Θέμα:** Προσωπική γυμναστική, προπονήσεις και ραντεβού με trainers.

## Ρόλοι

| Ρόλος | Βασικά δικαιώματα |
|---|---|
| Επισκέπτης (Anonymous) | Αναζητά και βλέπει trainers· δημιουργεί λογαριασμό Trainee ή Trainer. |
| Χρήστης (Trainee) | Login/logout, προφίλ και στόχοι, προβολή διαθέσιμων slots, δημιουργία/ακύρωση κράτησης και καταγραφή προόδου. |
| Trainer | Διαχειρίζεται διαθεσιμότητα, εγκρίνει/ακυρώνει αιτήματα ραντεβού, καταχωρίζει σημειώσεις και πλάνα προπόνησης. |

## Use cases / λειτουργικές απαιτήσεις

| ID | Use case | Actor | Αποτέλεσμα ή βασική απόκριση |
|---|---|---|---|
| FR1 | Εγγραφή και ταυτοποίηση | Επισκέπτης, Χρήστης, Trainer | Εγγραφή με ρόλο Trainee/Trainer· login με JWT· άκυρα credentials: `401`. |
| FR2 | Διαχείριση διαθεσιμότητας | Trainer | Καταχώριση χρονικών slots· παρελθοντικός χρόνος: `400`. |
| FR3 | Κράτηση προπόνησης | Χρήστης | Έλεγχος κανόνων, δέσμευση ώρας και συγχρονισμός ημερολογίου· σύγκρουση: `409`. |
| FR4 | Έγκριση ή ακύρωση ραντεβού | Trainer | Ενημέρωση κατάστασης· μη συμμετέχων χρήστης: `403`. |
| FR5 | Πρόοδος και πλάνα | Χρήστης, Trainer | Καταγραφή μετρήσεων από χρήστη και πλάνου από trainer· πρόσβαση μόνο στα επιτρεπόμενα προσωπικά δεδομένα. |
| FR6 | Προτεινόμενες ασκήσεις | Trainer | Ανάκτηση ασκήσεων από το εξωτερικό API ανά μυϊκή ομάδα. |

## Επιχειρησιακοί κανόνες

- Κάθε προπόνηση διαρκεί 60 λεπτά.
- Κάθε χρήστης έχει έως 3 ενεργά, μελλοντικά/μη ολοκληρωμένα ραντεβού.
- Δεν δημιουργείται ή τροποποιείται ραντεβού σε χρόνο πριν από το `LocalDateTime.now()`.
- Ένας trainer δεν έχει επικαλυπτόμενα ενεργά ραντεβού.
- Η αποτροπή double booking προστατεύεται συναλλακτικά στη βάση. Η τελική επιλογή lock ή DB constraint καταγράφεται στο σχέδιο υλοποίησης.

## Εξωτερικό API

- `GET /api/v1/exercises?muscleGroup={group}`: προτεινόμενες ασκήσεις.
- `POST /api/v1/calendar/events`: δέσμευση ημερολογίου· επιστρέφει `externalEventId`.
- Απαιτείται `X-API-Key` από τη μεταβλητή `EXTERNAL_API_KEY`. Connect timeout: 2s, read timeout: 3s. Bounded retry έως 2 φορές για GET· χωρίς αυτόματο retry για POST.
